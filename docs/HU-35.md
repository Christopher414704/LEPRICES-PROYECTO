# HU-35 – Identificar visualmente el sistema de tracción

**Estado:** Implementada.

La ficha técnica de FAXCAR y su informe PDF muestran un esquema de las ruedas motrices del vehículo seleccionado. Para automóviles distingue tracción delantera, trasera, integral AWD y 4WD, conservando la denominación que ofrece la fuente. Para motocicletas usa un esquema de dos ruedas.

El esquema usa la tracción de la ficha del catálogo o una propuesta documental con cita y enlace HTTPS. Las ruedas se resaltan únicamente si la descripción identifica un sistema único y cuenta con ese respaldo. Los datos investigados que aún requieren revisión se etiquetan como tales; una referencia del catálogo tampoco se presenta como inspección o confirmación de la unidad.

Una contradicción, una descripción que mezcla alternativas (por ejemplo, AWD/4WD), menciones negadas u opcionales o expresiones insuficientes como `4x2` y `2WD` dejan todas las ruedas sin resaltar. `4x2` solo puede completarse si otra evidencia identifica expresamente el eje, como `RWD`; nunca determina por sí solo el eje motriz. El informe conserva el mismo estado y no resuelve discrepancias por su cuenta.

La clasificación se comparte entre API y web en `apps/shared/traccion.mjs`. Las fuentes que dicen `FWD` y `Front-Wheel Drive` son equivalentes; `AWD` y `4WD` siguen siendo sistemas distintos. Una fuente que solo publica `integral` o `4x4` permite representar cuatro ruedas, conservando «AWD/4WD sin especificar». Una propuesta sin respaldo no añade esa precisión. También se revisan las evidencias agrupadas y sus posibles contradicciones.

La tabla, el diagrama accesible y el PDF usan la misma interpretación. Las ruedas motrices llevan una `M` además del color, y un texto identifica las ruedas representadas; el frente del vehículo y el esquema estrecho de dos ruedas distinguen la motocicleta. Los modos integrales se describen según su funcionamiento, sin afirmar que las cuatro ruedas reciben fuerza permanentemente. No se agregaron proveedores ni migraciones.

Validación: `pnpm test` (271 aprobadas, 7 pruebas de PostgreSQL omitidas por requerir activación explícita), `pnpm --filter @jalapa/web build`, revisión del diagrama en navegador y renderizado de ambos PDF con Poppler. Las pruebas de PDF reabren el archivo y verifican texto y cantidad de marcas motrices para delantera, trasera, AWD, 4WD, integral genérica, motocicleta, `4x2` y contradicciones. La investigación usa la revisión 14 para distinguir las evidencias procesadas con estas reglas.
