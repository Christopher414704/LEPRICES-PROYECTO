# HU-26 – Calcular ruta y costo estimado del viaje

**Estado:** Implementada. **Prioridad:** Alta.

La pantalla `/rutas.html`, accesible desde el mapa público y Mi Automóvil, permite elegir origen y destino, calcular ida, regreso o ambos sentidos y visualizar la carretera. La API consulta Valhalla; si falla muestra un error controlado. El usuario puede elegir explícitamente kilómetros manuales.

El presupuesto calcula litros = kilómetros × L/100 km ÷ 100, añade el margen indicado, convierte a galones estadounidenses (3.785411784 L) y multiplica por el precio. Usa precios vigentes GTQ de PostgreSQL: estación elegida o promedio de estaciones próximas al recorrido. Admite precio manual. Sin precio, el costo queda sin determinar. No incluye peajes, estacionamiento ni desvíos para abastecerse.

Los visitantes usan consumo manual; un conductor autenticado puede elegir su vehículo. El servidor valida propiedad y prioriza el consumo medido de HU-25 sobre el consumo combinado del catálogo. Si falta consumo, requiere entrada manual o parámetros explícitos del modelo teórico. Las rutas eléctricas usan kWh y tarifa manual.

API: `POST /api/publico/rutas/estimar`, `POST /api/rutas/estimar` y `GET /api/rutas/vehiculos/:id/consumo`. La ruta privada conserva sesión, rol conductor y validación de origen. Las respuestas usan `no-store` y los cálculos están limitados por IP. El proveedor tiene cola, timeout y caché acotados.

Configuración: `RUTAS_VALHALLA_URL` permite configurar el proveedor. El presupuesto normal y el modelo teórico no requieren Python. La simulación opcional FASTSim requiere instalar `apps/api/python/requirements.txt` y definir `RUTAS_FASTSIM_PYTHON` o crear `apps/api/.venv-fastsim`; si falta devuelve un error controlado. Sus resultados son estimaciones, no mediciones.

Verificación: 157 pruebas aprobadas, siete integraciones omitidas y compilación web correcta. Incluyen cálculos, conversiones, precios, acceso al garaje, autenticación, origen HTTP, límites, proveedor simulado, geometría, sentidos, elevación y errores. No se verificó el proveedor externo en vivo, PostgreSQL real ni la instalación de FASTSim.
