# HU-37 – Personalizar condiciones y modalidades de una ruta

**Estado:** Implementada. **Prioridad:** Alta.

La pantalla `/rutas.html` permite elegir una ruta más rápida, equilibrada o más corta y solicitar que se eviten peajes, autopistas y caminos no pavimentados. También conserva la modalidad de automóvil o motocicleta, tomada del vehículo del garaje cuando corresponde.

Las preferencias se aplican únicamente al cálculo automático por carretera. En kilómetros manuales se deshabilitan porque no existe una ruta que el proveedor pueda ajustar. Son preferencias, no garantías: una vía puede ser necesaria para completar el recorrido y la disponibilidad depende de los datos de OpenStreetMap.

La API valida los valores y tipos recibidos antes de consultar Valhalla. El perfil y las condiciones forman parte de la clave de caché para que dos configuraciones distintas nunca compartan una ruta. La respuesta devuelve las preferencias aplicadas y la interfaz las muestra junto al resultado.

No se incluyen ferries. La selección de prioridad usa la ponderación entre tiempo y distancia de Valhalla; las condiciones usan sus opciones de autopistas, peajes, pistas y superficies no pavimentadas.
