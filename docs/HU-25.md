# HU-25 – Registrar bitácora de combustible

**Prioridad:** Media

**Estado:** Implementada/Parcial

## Descripción

**Como:** conductor

**Quiero:** registrar las cargas de combustible de mi automóvil

**Para:** llevar control de consumo y rendimiento.

## Alcance implementado

Cada vehículo del garaje ofrece una bitácora propia. El conductor puede registrar fecha y hora, lectura del odómetro, litros cargados, costo total opcional, si llenó el tanque y notas. La misma sección muestra el historial del vehículo del registro más reciente al más antiguo.

La API valida el rol, el identificador del vehículo, la propiedad y todos los valores antes de escribir. La tabla `cargas_combustible` conserva la relación compuesta entre vehículo y propietario, incorpora restricciones numéricas y elimina sus registros únicamente cuando se elimina el vehículo correspondiente.

El rendimiento se calcula entre dos cargas con tanque lleno. Las cargas parciales intermedias se acumulan para obtener kilómetros por litro y un promedio ponderado del historial medible.

## API

- `GET /api/mi-automovil/vehiculos/:id/cargas`: consulta el historial y el rendimiento del vehículo autenticado.
- `POST /api/mi-automovil/vehiculos/:id/cargas`: registra una nueva carga para ese vehículo.

Ambas operaciones requieren una sesión de conductor. El registro también utiliza la protección de origen de la API.
