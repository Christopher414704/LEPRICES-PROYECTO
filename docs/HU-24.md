# HU-24 – Registrar mi automóvil

Estado: Parcialmente implementada. Prioridad: Media.

Como conductor quiero registrar mi automóvil para usar datos personalizados en consumo y rutas.

Incluye registro manual (tipo, marca, modelo, año, motor, transmisión y combustible opcionales), selección desde FuelEconomy, alias, kilometraje, consulta persistente y eliminación por propietario. La API exige sesión y rol conductor; toma el propietario de la sesión y la ficha del catálogo desde el servidor. No acepta un propietario ni una ficha de catálogo arbitrarios enviados por el cliente. Las fichas conservan consumos publicados en L/100 km, disponibles para integración posterior con rutas.

Validación: 24 pruebas API y nueve web aprobadas; compilación web correcta. La prueba PostgreSQL queda pendiente: Docker está apagado y el puerto 5433 rechaza la conexión.

No incluye bitácora, rutas, IA ni FAXCAR. El registro de cuentas HU-21 no está presente en esta copia: se requiere una cuenta conductor existente. Aplicar 0016_registrar_mi_automovil mediante el migrador normal antes de usar el módulo; este commit no ejecuta migraciones sobre datos reales.

Acceso: /mi-automovil.html; login redirige allí a conductores. Las cuentas de personal conservan su destino y no pueden consultar garajes. API: /api/mi-automovil/catalogo, /catalogo/:id, GET/POST /vehiculos y DELETE /vehiculos/:id. Las escrituras conservan validación de origen. La conexión efectiva con cálculos de rutas queda pendiente.
